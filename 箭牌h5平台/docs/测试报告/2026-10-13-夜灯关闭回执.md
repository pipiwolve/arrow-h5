# 关掉马桶夜灯的回执

- 日期：2026-10-13
- 页面：`app.js?v=43`
- 服务：本机 `http://127.0.0.1:8916`，`IOT_MODE=mock`

## 结论

「关掉马桶的夜灯。」由本机设备确认处理。识别结果已经发出后，松手不再把「识别中…」写回去。房间晚到的最终识别句会进入同一条确认。设备列表挂住超过 4 秒时，用本地清单继续匹配，对话留下 6 台马桶的选择卡。指令是 `switch_night_light`，取值 `off`。

## 检查

| 检查 | 结果 |
| --- | --- |
| `npm run check` | 通过。`send-text ok`，`selfcheck ok`，`turn-gate ok` |
| 按住期间结果先到 | 发出后提示被清掉，随后的松手不再写「识别中…」 |
| 房间最终句 `[Q]:关掉马桶的夜灯。` | 用户原话一条，助手回复「有多台设备符合，选一台再下发。」，并有选择卡 |
| 领代号被下一句作废 | 对话留下「设备列表没有取到」，占位「正在确认设备…」被替换 |
| 设备列表挂起 | 4 秒后回退，选择卡 6 台，品类都是马桶 |
| `POST /api/intent` | 返回同上固定回复，6 台马桶，`switch_night_light/off` |

这一轮没有进 BRTC 房间，没有在手机上按住说话。房间是否按时送出最终识别句，要在客户那次通话里再看。
