# △ 注意事项

☐ 本产品适用于海拔2000m以下的地区使用。

☐ 本产品连接水源时，适用水压范围：静压 0.02–0.75MPa。

☐ 使用随本产品附带的新软管组件，旧软管组件不宜重复利用。

☐ 如果电源软线损坏，为了避免危险，必须由制造商、其服务机构或类似的专业人员更换。

☐ 本产品属于固定式器具，应由专业人士进行安装、固定于特定位置使用。

☐ 本产品不打算由存在肢体、感官或精神能力缺陷或缺少使用经验和知识的人（包括儿童）使用，除非有负责他们安全的人对他们进行与器具使用有关的监督或指导。

☐ 应照看好儿童，确保他们不玩耍本产品。

☐ 本产品只能与随机配送的停电冲水电池包配套使用。

☐ 产品遥控器使用7号电池供电。

☐ 本产品电池盒使用5号电池供电。

☐ 抓住电池盒本体，向上提拉电池盒上盖即可打开电池盒，打开后可见内部的电池仓，按电池仓上的电池极性提示标注依次插入电池。

☐ 严禁对不可充电电池进行充电。

☐ 请勿混合使用新旧电池。

☐ 请按电池盒电池仓中 + - 正确安装电池。

电池能量耗尽时应及时取出电池，更换新电池。

☐ 废弃电池时，请用胶带等进行绝缘。

☐ 请将电池放置在婴幼儿够不到的地方。

☐ 如果产品电池盒长期存放不用，应取出电池。

电池盒的供电端子不应短路。

☐ 使用过程中，请将家用电器的电源插头完全插入电源插座中，并保持电源插头与插座接触良好。

☐ 当需要使用延长线电源插座时，请使用符合国家标准要求的延长线电源插座。

□ 产品出现异常噪声、异常气味、异常高温或故障时，请立即停止使用，关闭开关，断开电源。

☐ 使用者不应自行拆卸家用电器，不应变更内部接线、部件和保护装置。

☐ 从插座上拔下插头时，不应对电源线施加拉力。

# △ 注意事项

☐ 在使用过程中，请保持皮肤紧贴座圈感应区域，否则会导致自动冲水误触发或不触发。 $ ^{*} $儿童使用时，接触感应区域会比较难。

☐ 请不要向产品内冲入新闻纸、纸尿垫、妇用卫生巾等容易堵塞的物品。

☐ 请不要在 $ 0^{\circ} $C以下环境中使用，否则水结冰膨胀会挤破陶瓷体。

 $ ^{*} $否则容易引起漏水导致财产损失。

☐ 当突然停电时，请拔掉电源插头，关闭止水阀，防止漏水。

 $ ^{*} $否则容易引起漏水导致财产损失。

☐ 请避免阳光直射或将取暖器材靠近本产品。

 $ ^{*} $否则可能造成产品变色。

☐ 请不要用重力撞击陶瓷，以防止破损漏水。

☐ 请不要在产品底座埋入胶凝材料（水泥砂浆等），以防止因膨胀而撑裂便器。违规操作造成的不良后果本公司概不负责。

☐ 出差或外出旅游等长时间不使用时，请您务必拔掉电源插头、关闭水源，并将产品内部积水排净。 $ ^{*} $否则冻结内部积水引起的破损会导致火灾、漏水。

☐ 在寒冷的冬季，当产品在经过长途运输或长时间存放时，产品内剩下的积水可能会发生冻结现象。为预防冻结造成损坏，请采取防冻措施。

 $ ^{*} $否则冻结内部积水引起的破损会导致火灾、漏水。

☐ 在安装本产品的同一房间内，需要在触手可及的位置安装一个止水阀，用于紧急情况下，无需借助工具即可切断本产品的进水水路，否则产品的意外故障可能会导致用户损失。

为避免由热断路器的误复位产生危险，器具不能通过外部开关装置供电，例如定时器，或者连接到根据功能有规则地进行通、断的电路。

☐ 请勿用湿手触摸或插拔电源插头。

 $ ^{*} $否则有触电的危险。

☐ 请勿使用不良的电源插座或破损的电源插头。

 $ ^{*} $否则接触不良、破损等导致触电或引发火灾等危险。

□ 使用的电源插座请在规定的范围（交流 $ 220V \pm 10\% $，最大电流10A以上）。

 $ ^{*} $否则容易引起火灾、触电。

☐ 请勿把电源线随意拉拽、强行弯曲和扭曲、拉伸、卷曲、打捆、承重、过度夹挤。 $ ^{*} $否则电源线破损会导致触电或火灾。

☐ 非本公司售后维修人员或指定专业维修人员，严禁拆卸、修理、改装本产品。

 $ ^{*} $否则容易引发触电、火灾或异常运作造成人身伤害。

☐ 请勿将点燃的香烟及其他燃烧物投入产品内。

 $ ^{*} $否则容易发生火灾。

☐ 请勿在雷电天气下使用（在附近发生雷电时，请拔下电源插头）。

 $ ^{*} $否则可能会引发事故或发生故障。

☐ 座圈与盖板发生损坏时，为了避免危险请您务必拔掉电源插头、关闭水源，并请联系当地经销商进行更换。

 $ ^{*} $否则容易发生触电、火灾的危险。

☐ 请定期将电源插头拔下，用干布擦拭电源插头上的灰尘。

 $ ^{*} $否则当绝缘不良时，会引起火灾。

☐ 清洁保养塑料部分时，请勿使用不适合的清洁剂（如浓硫酸、浓硝酸、冰醋酸、四氯化碳、氯仿、丙酮、丁酮、苯、甲苯、苯酚、甲酚、二甲基替甲酰胺、甲醚、大豆油、醋酸盐、40%硝酸、浓盐酸、95%酒精、汽油、煤油、刹车油等）。

 $ ^{*} $否则可能导致塑料部分开裂会造成人身伤害、触电或引起火灾。

☐ 请勿将尿液淋在本体上。

 $ ^{*} $否则会导致故障或出现粉色和茶色等污迹。

☐ 请避免安装在潮湿及易浸到水的浴室内使用。请勿将水喷淋到本产品上面或用水冲洗，以防内部进水，造成损失。

 $ ^{*} $否则容易引起触电、火灾。

☐ 请勿使用工业用水或污染的水源。

 $ ^{*} $否则有可能引起膀胱炎、皮炎及因机械内部腐蚀引起触电、火灾。

☐ 请不要用力向后倚靠、站立在盖板上，或粗暴开闭盖板、座圈，以免造成损坏。

 $ ^{*} $否则容易发生破损、造成人身伤害。

☐ 请勿向产品或遥控器内部加水或清洁剂。请勿用水或清洁剂弄湿产品及电源插头。 $ ^{*} $否则可能会有触电和发生火灾的危险。

# 法恩莎智联小程序和NFC

3、功能联动，设置NFC联动，快速执行多个预定产品功能；（NFC贴附于说明书包装袋内，您可自行选择合适位置粘贴）

# 侧面功能键

1、短按侧面功能按键：执行一次冲水功能；

2、长按侧面功能按键约3秒蜂鸣器“嘀”一声，

座温调节一档，档位按0-1-3-5-0档的顺序调节。

# 座圈加热

离座状态下，长按侧面功能键约3秒或长按遥控器的“冲水”键约3秒或操作手机小程序开启/关闭座圈加热。

1、座温调节有六档，分别为1档、2档、3档、4档、5档和0档（座温关闭）；

2、在设置座圈档位时，每调节一档蜂鸣器响一声，调节至0档时蜂鸣器响两声；

3、当设定档位高于1档，用户着座后，先加热到用户设定档位，然后保持加热5分钟后档位自动调节到1档进行加热。用户离座后则按照原设定的档位进行加热；

4、落座状态下，调节座温档位高于1档时，先加热到用户设定档位，然后保持加热5分钟后档位自动调节到1档进行加热。

# 备注：

1、长按侧面功能键约3秒或长按遥控器的“冲水”键按0-1-3-5-0档的顺序进行调节，手机小程序可进行任意档位调节；

2、落座状态下，优先加热到用户设定档位目标温度（最长加热时间保护限定为5分钟）。

# 冲水功能

短按机芯功能键或操作手机小程序会执行一次冲水功能。启动一次冲水后，需要一段补水时间（约30秒），补水期间启动冲水操作不会启动冲水且蜂鸣器响两声。

# 润瓷功能

当系统检测到有人成功着座时，如果润瓷功能开启的情况下，陶瓷便池内会自动洗刷2秒。

润瓷功能开关：长按遥控器“翻圈”键或操作手机小程序，可开启/关闭润瓷功能。

蜂鸣器响1声为功能开启，响2声为功能关闭。

备注：如果自动发泡功能开启的情况下，落座是触发发泡功能而不是润瓷功能。

# 夜灯功能

约5分钟无操作自动关闭。

短按遥控器“夜灯”键或操作手机小程序可开启/关闭。

备注：有用户操作包括：触发按键、触发遥控器、触发脚感、落座、微波模块检测到用户。

# 使用操作

# 感应夜灯

1、按住机芯侧面按键，再短按遥控器的“夜灯”键或操作手机小程序可切换感应夜灯的功能开关；

2、感应夜灯功能开启时，用户靠近马桶前端时，夜灯自动打开；马桶检测到用户离开10秒后，夜灯自动关闭。

3、感应夜灯功能的感应距离与自动翻盖的感应距离一致；

4、在冲水/润瓷/翻盖翻圈功能过程中，不执行微波感应功能，待以上动作执行完毕，微波感应自动恢复。

# 使用操作

# 脚触翻盖翻圈

1、脚触时间小于2秒为短触，脚触时间大于2秒为长触。短触时要脚离开感应区后才触发相应的动作，长触时感应时间大于2秒后才触发相应的动作。

2、短触功能：

2.1若当前座盖关闭状态，进行短触，触发翻盖功能；

2.2 若当前座盖打开状态，落座使用后离座，进行短触，触发合盖冲水功能；

2.3若当前座盖打开状态，无落座，进行短触，触发翻圈功能；

2.4若当前座圈打开时间小于5秒，进行短触，触发合圈功能；

2.5若当前座圈打开时间大于5秒，进行短触，触发合盖冲水功能；

2.6若当前座盖在打开过程中，进行短触，座盖完全打开后执行翻圈功能；

2.7若当前座圈在关闭过程中，进行短触，触发合盖功能；

2.8若当前处于落座状态下，进行短触，触发一次泡沫盾功能。

3、脚部接触陶瓷侧面感应区进行长触：

3.1若当前处于离座状态下，进行长触，触发一次泡沫盾功能；

3.2若当前处于落座状态下，进行长触，如果产品刚上电一分钟内，可开启/关闭自动发泡功能。

备注：座盖打开周期内，离座状态下，发生过冲水动作，合盖合圈后不进行冲水动作。

操作手机小程序可开启/关闭脚触功能。

# 自动翻盖功能

1、自动翻盖功能开启时，用户靠近马桶前端范围内，座盖自动打开；

2、在冲水/润瓷/翻盖翻圈功能过程中，不执行微波感应功能，待以上动作执行完毕，微波感应自动恢复；

3、按住机芯侧面按键的同时，短按遥控器的“翻圈”键或操作手机小程序可设置产品检测到用户靠近自动翻盖的距离档位。距离档位共有五档。

用手机小程序的方式操作可调节五档，用按住机芯侧面按键的同时，短按遥控器的“翻圈”键的方式操作可调节三档，取1、3、5档。

4、按住机芯侧面按键的同时，长按遥控器的“翻圈”键或操作手机小程序，可开启/关闭自动翻盖功能。蜂鸣器响1声为功能开启，响2声为功能关闭。

# 智慧温感

智慧温感功能开启时，坐便器会根据室温自动调节座温至对应的设定温度。

智慧温感功能开启后，仍保留防低温烫伤功能。除室温>28°C时，直接关闭座圈加热；其它维持在一档座温加热。

操作手机小程序开启/关闭智慧温感功能。蜂鸣器响1声为功能开启，响2声为功能关闭。

智慧温感功能开启时，用户主动调节座温档位，会直接关闭智慧温感功能。
