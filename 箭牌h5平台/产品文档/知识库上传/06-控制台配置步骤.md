# 控制台配置步骤

模板继续用 `arrow_product_kb`（ID 10000101）。旧的三条是占位，配完新意图后再删。文案以 `05-知识库意图填写稿.md` 为准，本文件只写点击顺序。

做完后的结果：4 个知识库，7 条意图，每条只挂 1 个库。页面上不再有「型号规格」「语音能控制什么」「保养或离线与报修说明」。

## 1. 先建库并上传

在平台的知识库管理里新建 4 个库。不要把新文件传进现有的「箭牌产品知识库」。

| 新建的库名 | 上传的文件 | 不要同时上传 |
| --- | --- | --- |
| 箭牌AKB1357知识库 | `01-箭牌-AKB1357L-M.md` | 其他三份 |
| 法恩莎FLM0814知识库 | `02-法恩莎-FLM0814S-QL-QM.md` | 其他三份 |
| 安华NiL125知识库 | `03-安华-NiL125L-M.md` | 其他三份 |
| 三款对照知识库 | `04-三款对照.md` | 其他三份 |

	切片方式若可选，选按 Markdown 标题。四个库都要等到「已上传」且状态可用，再做下一步。解析中的库不要先挂到意图上。

`00-上传与切片说明.md` 和 `05-知识库意图填写稿.md` 不上传。

## 2. 改模板描述

打开模板 `arrow_product_kb`。右上角点「编辑」，只改模板描述，名称和 ID 不动。描述换成 `05` 里「模板描述」那一段，保存。

这段描述把范围收成三份说明书，并写明控设备、建场景、打开报修页不走本模板。

## 3. 新建七条意图

仍在这个模板页。对下面每一条：点「添加意图」，填完再点「确定」。不要编辑旧的三条来改名，占位例句和旧库绑定会留脏。

每一条的填法相同：

1. 意图名称：粘贴 `05` 里该条的名称。
2. 意图描述：粘贴该条描述。字数应在 200 字以内，上限 1000。
3. 意图例句：第一条填进默认输入框。其余点「添加例句」，一条一个框。每条不超过 40 字。
4. 快速匹配短语：点「已配置 0 条」右侧铅笔，按 `05` 逐条加入，保存回表单。
5. 知识库：点「添加知识库」，只选该条写明的那一个库。不要多选，不要选「箭牌产品知识库」。
6. 点「确定」。回到列表后，这条应显示「可用文件 1、已上传文件 1」。

按这个顺序建，避免对照意图先抢走单型号问题：

1. 箭牌AKB1357功能参数 → 箭牌AKB1357知识库
2. 法恩莎FLM0814功能参数 → 法恩莎FLM0814知识库
3. 安华NiL125功能参数 → 安华NiL125知识库
4. 箭牌AKB1357故障保修 → 箭牌AKB1357知识库
5. 法恩莎FLM0814故障保修 → 法恩莎FLM0814知识库
6. 安华NiL125故障保修 → 安华NiL125知识库
7. 三款坐便器对照 → 三款对照知识库

第 4 条的快速匹配里才有「显示E1」。不要把这四个字加到安华那条。第 7 条不要加「区别」。

这一步做完时，列表里会暂时同时有旧 3 条和新 7 条。先不要拿线上流量做验收。

## 4. 删除三条占位意图

七条都显示已挂上文件之后，再删占位。在每条右侧点「删除」，并在确认框里确认。

删除这三条，名称必须对得上：

- 型号规格
- 语音能控制什么
- 保养或离线与报修说明

不要删刚刚新建的七条。删完列表应只剩七条。

「箭牌产品知识库」此时不再被本模板引用。不要往里面补传新说明书。其他模板若还挂着它，先不要删这个库。

## 5. 保存后核对

列表上逐条看一遍：

- 意图 1、4 的知识库都是箭牌AKB1357知识库。
- 意图 2、5 都是法恩莎FLM0814知识库。
- 意图 3、6 都是安华NiL125知识库。
- 意图 7 是三款对照知识库。
- 每条都是可用文件 1、已上传文件 1。
- 快速匹配条数分别为 4、4、5、4、4、4、4。

然后用 `产品文档/知识库测试集/产品问答测试集.jsonl` 回放。先跑这六句，确认路由没有串库，再跑满 52 条：

| 原话 | 应走的意图 | 回答里要出现 |
| --- | --- | --- |
| AKB1357额定功率多少 | 箭牌功能参数 | 900W |
| FLM0814有臀洗吗 | 法恩莎功能参数 | 没有 |
| NiL125功率是多少 | 安华功能参数 | 790W |
| AKB1357显示E1是什么 | 箭牌故障保修 | E1 |
| 安华客服电话多少 | 安华故障保修 | 400-1066-828 |
| 哪一款没有臀洗 | 三款对照 | 法恩莎或 FLM0814 |

「座温能不能用语音调」不应再由知识库意图作答。这句话走设备控制，或由助手说明说明书未记载语音下发。
