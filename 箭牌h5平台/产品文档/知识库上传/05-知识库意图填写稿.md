# 知识库意图填写稿

模板仍用 `arrow_product_kb`。先改模板描述，再删掉原来的三条意图，按下面七条新建。每条意图只挂一个知识库。

表单限制：意图名称最多 40 字；描述最多 1000 字；每条例句最多 40 字。名称只用汉字、英文字母、数字和下划线。

## 要建几个知识库

建四个库，不要把四份文件放进原来那一个「箭牌产品知识库」。

| 知识库名称 | 只上传 |
| --- | --- |
| 箭牌AKB1357知识库 | `01-箭牌-AKB1357L-M.md` |
| 法恩莎FLM0814知识库 | `02-法恩莎-FLM0814S-QL-QM.md` |
| 安华NiL125知识库 | `03-安华-NiL125L-M.md` |
| 三款对照知识库 | `04-三款对照.md` |

一个库里堆三个品牌时，「功率多少」「客服电话」会同时召回 900W、790W、85W 和三个热线。分成三个库之后，单型号问题只在一个库里检索。对照问题单独走第四个短文件，避免把三本说明书切碎后混答。

原来的三条意图都挂着同一个库，而且例句里有 AKB1332-P、AKB1621。这两款不在本次说明书里，留着会把不存在的资料路由进来。

## 这次只改什么

库、文件、例句和快速匹配短语都不用动。七条意图的执行位置保持平台侧知识库检索，不要改成发送 SDK 消息。

只替换模板描述和七条意图描述。旧描述里写了功率、电话和故障码，模型会先口头说「准备查看」，检索慢时句子就停在这里。新描述只写什么问题用这条意图，数字仍从挂载的文档里取。

改完后保存，等意图重新生效，再问一次「AKB1357的额定功率是多少」。合格回答第一句就是 900W，不要以「准备查看」开头。

## 模板描述

替换基本信息里的模板描述：

```
用户询问箭牌AKB1357、法恩莎FLM0814S-Q、安华NiL125的功能、参数、用法、故障、保养或保修时使用。回答直接使用检索到的原文，第一句给出结论。检索没有该事实时说说明书未记载。用户要立刻操作设备、建场景或打开报修页时不使用本模板。
```

## 不要保留的旧意图

- 「型号规格」：例句指向未供稿型号，整条删除后用下面三条功能意图替换。
- 「语音能控制什么」：三份说明书没有可下发指令表。挂上新文件后，模型会把遥控器按键说成可以语音控制。本模板不再建这条。语音下发仍走设备控制，不走知识库。
- 「保养或离线与报修说明」：清洁、滤芯、故障、保修留在各品牌的故障意图里。设备离线原因和报修进度不在说明书中，不要再挂知识库回答。
