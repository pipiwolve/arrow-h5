# △ 注意事项

☐ 本产品适用于海拔2000m以下的地区使用。

☐ 本产品连接水源时，水压范围：静压 0.10–0.75MPa。

☐ 使用随本产品附带的新软管组件，旧软管组件不宜重复利用。

☐ 如果电源软线损坏，为了避免危险，必须由制造商、其服务机构或类似的专业人员更换。

☐ 本产品属于固定式器具，应由专业人士进行安装、固定于特定位置使用。

☐ 本产品不打算由存在肢体、感官或精神能力缺陷或缺少使用经验和知识的人（包括儿童）使用，除非有负责他们安全的人对他们进行与器具使用有关的监督或指导。

应照看好儿童，确保他们不玩耍本产品。

☐ 本产品只能与随机配送的停电冲水电池包配套使用。

☐ 产品遥控器使用7号电池供电。

☐ 本产品电池盒使用5号电池供电。

☐ 抓住电池盒本体，向上提拉电池盒上盖即可打开电池盒，打开后可见内部的电池仓，按电池仓上的电池极性提示标注依次插入电池。

☐ 严禁对不可充电电池进行充电。

☐ 请勿混合使用新旧电池。

☐ 请按电池盒电池仓中 + - 正确安装电池。

电池能量耗尽时应及时取出电池，更换新电池。

☐ 废弃电池时，请用胶带等进行绝缘。

□ 请将电池放置在婴幼儿够不到的地方。

☐ 如果产品电池盒长期存放不用，应取出电池。

电池盒的供电端子不应短路。

☐ 本产品必须可靠接地。

☐ 使用过程中，请将家用电器的电源插头完全插入电源插座中，并保持电源插头与插座接触良好。

当需要使用延长线电源插座时，请使用符合国家标准要求的延长线电源插座。

□ 产品出现异常噪声、异常气味、异常高温或故障时，请立即停止使用，关闭开关，断开电源。

☐ 使用者不应自行拆卸家用电器，不应变更内部接线、部件和保护装置。

☐ 从插座上拔下插头时，不应对电源线施加拉力。

# △ 注意事项

☐ 请勿长时间使用座温、暖风/风温的「高」、「中」档。

 $ ^{*} $否则长时间使用会有烫伤的危险。

☐ 在使用过程中，请保持皮肤紧贴座圈感应区域，否则产品会停止清洗或暖风烘干功能。 $ ^{*} $儿童使用时，接触感应区域会比较难。

☐ 请勿将小便淋于清洗器的喷嘴上。

 $ ^{*} $否则产生污垢导致堵塞。

☐ 请不要向产品内冲入新闻纸、纸尿垫、妇用卫生巾等容易堵塞的物品。

☐ 请不要在 $ 0^{\circ} $C以下环境中使用，否则水结冰膨胀会挤破陶瓷体。

 $ ^{*} $否则容易引起漏水导致财产损失。

☐ 当突然停电时，请拔掉电源插头，关闭止水阀，防止漏水。

 $ ^{*} $否则容易引起漏水导致财产损失。

☐ 请避免阳光直射或将取暖器材靠近本产品。

 $ ^{*} $否则可能造成产品变色。

☐ 请不要用重力撞击陶瓷，以防止破损漏水。

☐ 请不要在产品底座埋入胶凝材料（水泥砂浆等），以防止因膨胀而撑裂便器。违规操作造成的不良后果本公司概不负责。

☐ 拆卸过滤器时，请务必关闭止水阀。另外安装过滤器时，请用力拧紧。

 $ ^{*} $否则容易引起漏水

☐ 出差或外出旅游等长时间不使用时，请您务必拔掉电源插头、关闭水源，并将产品内部积水排净。 $ ^{*} $否则冻结内部积水引起的破损会导致火灾、漏水。

☐ 在寒冷的冬季，当产品在经过长途运输或长时间存放时，产品内剩下的积水可能会发生冻结现象。为预防冻结造成损坏，请采取防冻措施。

 $ ^{*} $否则冻结内部积水引起的破损会导致火灾、漏水。

☐ 在安装本产品的同一房间内，需要在触手可及的位置安装一个止水阀，用于紧急情况下，无需借助工具即可切断本产品的进水水路，否则产品的意外故障可能会导致用户损失。

# △警告

为避免由热断路器的误复位产生危险，器具不能通过外部开关装置供电，例如定时器，或者连接到根据功能有规则地进行通、断的电路。

☐ 请勿用湿手触摸或插拔电源插头。

 $ ^{*} $否则有触电的危险。

☐ 请勿使用不良的电源插座或破损的电源插头。

 $ ^{*} $否则接触不良、破损等导致触电或引发火灾等危险。

□ 使用的电源插座请在规定的范围（交流 $ 220V \pm 10\% $，最大电流10A以上）。

 $ ^{*} $否则容易引起火灾、触电。

☐ 请勿把电源线随意拉拽、强行弯曲和扭曲、拉伸、卷曲、打捆、承重、过度夹挤。 $ ^{*} $否则电源线破损会导致触电或火灾。

☐ 非本公司售后维修人员或指定专业维修人员，严禁拆卸、修理、改装本产品。

 $ ^{*} $否则容易引发触电、火灾或异常运作造成人身伤害。

☐ 请勿将点燃的香烟及其他燃烧物投入产品内。

 $ ^{*} $否则容易发生火灾。

☐ 请勿在雷电天气下使用（在附近发生雷电时，请拔下电源插头）。

 $ ^{*} $否则可能会引发事故或发生故障。

☐ 座圈与盖板发生损坏时，为了避免危险请您务必拔掉电源插头、关闭水源，并请联系当地经销商进行更换。

 $ ^{*} $否则容易发生触电、火灾的危险。

☐ 请定期将电源插头拔下，用干布擦拭电源插头上的灰尘。

 $ ^{*} $否则当绝缘不良时，会引起火灾。

☐ 清洁保养塑料部分时，请勿使用不适合的清洁剂（如浓硫酸、浓硝酸、冰醋酸、四氯化碳、氯仿、丙酮、丁酮、苯、甲苯、苯酚、甲酚、二甲基替甲酰胺、甲醚、大豆油、醋酸盐、40%硝酸、浓盐酸、95%酒精、汽油、煤油、刹车油等）。

 $ ^{*} $否则可能导致塑料部分开裂会造成人身伤害、触电或引起火灾。

☐ 请勿将小便射进暖风出口位置。

 $ ^{*} $否则有触电的危险。

☐ 请避免安装在潮湿及易浸到水的浴室内使用。请勿将水喷淋到本产品上面或用水冲洗，以防内部进水，造成损失。

 $ ^{*} $否则容易引起触电、火灾。

☐ 请勿使用工业用水或污染的水源。

 $ ^{*} $否则有可能引起膀胱炎、皮炎及因机械内部腐蚀引起触电、火灾。

☐ 请不要用力向后倚靠、站立在盖板上，或粗暴开闭盖板、座圈，以免造成损坏。

 $ ^{*} $否则容易发生破损、造成人身伤害。

☐ 请勿将手或其他东西塞入暖风出口，在产品使用时请勿覆盖暖风出口。

 $ ^{*} $否则容易引发触电、火灾或异常运作造成人身伤害。

☐ 请勿向产品或遥控器内部加水或清洁剂。请勿用水或清洁剂弄湿产品及电源插头。

 $ ^{*} $否则可能会有触电和发生火灾的危险。

# 4、遥控器的安装

建议将遥控器安装在离坐便器较近的位置，在墙面上选择合适的高度。

1、在墙面上钻两个直径约为6mm，深度约为32mm的孔；

2、用锤子把膨胀胶粒轻轻的打入孔中；

3、用所配的螺钉，把遥控器支架固定到墙面上。

4、将遥控器电池区后盖打开，换上新的电池后，将遥控器放置在遥控器支架上。

# 遥控器的使用方法

# 指示灯显示

关闭0档，指示灯常灭；

1档：第1颗指示灯常亮；

2档：第1、2颗指示灯常亮；

3档：第1、2、3颗指示灯常亮；

4档：第1、2、3、4颗指示灯常亮；

5档：第1、2、3、4、5颗指示灯常亮。

# 冲水

按下此键，马桶执行一次冲水动作，提示音响一声。当不满足冲水条件时，提示音响两声。可通过小程序遥控触发大小冲。（注：冲水结束后需要等待约30秒才能再次进行冲水。）

# 臀洗

当座圈感应到有人落座，在停止或其他模式下按遥控器的“臀洗”键，蜂鸣器鸣叫一声，开始臀部移动清洗功能（再次按下此键则停止移动清洗），90秒后自动结束。可通过小程序遥控使用该功能。

# 妇洗

当座圈感应到有人落座，在停止或其他模式下按遥控器的“妇洗”键，蜂鸣器鸣叫一声，开始妇洗移动清洗功能（再次按下此键则停止移动清洗），90秒后自动结束。可通过小程序遥控使用该功能。

# 喷枪位置调节

按下喷嘴位置√或△键，可设定“臀洗”或“妇洗”模式中的喷枪位置，每按下喷枪位置√或△键，喷枪位置就会缩短或伸长清洗位置，指示灯对应档位显示，产品会“叮”响一声；当喷枪位置调节到最长或最短时，产品会连续“叮叮”响两声。

# 水压调节

按下清洗强度－或＋键，可设定“臀洗”或“妇洗”模式中的水压强度。每按下清洗强度－或＋键，水压就会降低或提升一档，指示灯对应档位显示，产品会“叮”响一声，清洗强度调节到最低或最高档时，产品会连续“叮叮”响两声。

# 停止

按下此键，可以结束“臀洗”、“妇洗”、“烘干”等功能。

# 水温

按下此键，依次改变臀洗(妇洗)清洗水加热档位：关闭档、1-2-3-4-5-4-3-2-1档、关闭档，调节水温时，遥控器指示灯按指示灯显示说明指示档位值。

# 座温

按下此键，依次改变座圈加热档位：关闭档、1-2-3-4-5-4-3-2-1档、关闭档。调节座温时，遥控器指示灯按指示灯显示说明指示档位值。

# 烘干

当座圈感应到有人落座，在停止或其他模式下按遥控器的“烘干”键，产品会“叮”响一声，然后开始烘干功能（落座后首次烘干前会先冲水一次），3分钟后自动结束。如果该功能启动后人员离开座圈，即退出该功能。可通过小程序遥控使用该功能。

# 风温

按下此键，依次改变烘干模式中的加热档位：关闭档、1-2-3-4-5-4-3-2-1档、关闭档。调节风温时，遥控器指示灯按指示灯显示说明指示档位值。

# 清洗模式

开启水温时，按下此键，执行一次清洗模式切换动作。清洗过程中按下遥控器“清洗模式”键，打开冷热按摩清洗，再次按下遥控器“清洗模式”键，关闭冷热按摩清洗。

# 喷枪清洁

长按“喷嘴位置 ^”键，喷枪喷头伸出，可以手工对喷头进行清洁处理，有落座或者长按遥控器“喷嘴位置 ^”键及产品侧面“冲水/退出”按键时自动缩回。 $ ^{*} $该功能只能在人体或其它物品未接触座圈感应区域下使用。

# 夜灯

按下此键，可以打开/关闭夜灯。

# 其他功能设定

# 落座检测

座圈上具有落座感应，用于检测有无用户落座。检测到有用户落座，才能开启“臀洗”、“妇洗”、“烘干”功能。“臀洗”、“妇洗”、“烘干”功能一经打开后，检测到用户离座，上述功能将自动关闭。用户离开落座感应区2秒后视为离座。

# 烘干风扇检测

在产品进入烘干功能后，系统会自动检测风扇的状态，当检测到风扇异常(例如：风扇线断开、卡死等)，烘干功能将自动结束、此功能用于保护烘干发热丝，防止其在无风状态下“干烧”。

# 防低温烫伤

座圈加热功能开启后，用户落座时，座温自动降到“1”档；落座使用中，用户主动调节座温档位，座温加热到设置档位并维持座温5分钟，自动降到“1”档加热，以防止低温烫伤。用户离座后，座温自动恢复到用户当前设定的加热档位。

# 落座自动润瓷

用户落座后，陶瓷洗刷约4秒。

小程序控制开关自动润瓷功能。

# 脚触功能开关

该功能开关，控制脚触模块使用。打开功能开关，有效使用，蜂鸣器响一声；关闭功能开关，失效使用，蜂鸣器响两声。

1. 小程序可操作脚感功能开关打开或关闭。

2. 离座状态下，长按遥控器“烘干”键，可切换脚感功能开关打开或关闭。

# 脚触冲水功能

离座状态下，触碰脚触感应区域，执行一次冲水功能。

# 停电冲水

在智能坐便器停电状态下，插入电池包，并按下电池包上面的按钮，电池包灯光亮起，表示正常给机芯供电，同时开启停电冲水一次。若需要再次冲水，需等待电池包灯光熄灭，再次按下按钮。

# 注：

1、停电冲水不能替代正常冲水功能，只能在特殊情况下使用；2、如出现非正常冲水现象请及时更换新电池。

温馨提示：建议使用电池盒时，将电池盒放置于马桶盖上方或者其他支撑台面上，以免电池盒长期悬空损坏电源线，使用结束后及时将电池盒取下，避免划花马桶外壳。

# 离座智感冲水功能

1. 当自动冲水功能开启，离座智感冲水功能开启时：

a)落座传感器检测到用户落座不超过7秒，离座后，不进行冲水；

b)落座传感器检测到用户落座超过7秒但小于45秒，离座后，进行小冲；

c)落座传感器检测到用户落座超过45秒，离座后，进行大冲；

2) 落座传感器检测到用户落座后，执行过妇洗，离座后，进行小冲；

3)落座传感器检测到用户落座后，执行过臀洗，离座后，进行大冲；

2. 当自动冲水功能开启，离座智感冲水功能关闭时：

# 3. 当自动冲水功能关闭时：

1) 离座自动冲水功能有效打开，着座时间超过7秒，离座后5秒自动（大冲）冲水一次；

1)无论是否执行过清洗以及落座时间是否满足离座智感冲水和离座自动冲水的条件，都不进行自动冲水。

# 节能功能

1. 节能功能具有开关。节能开关打开时，提示音一声，节能开关关闭时，提示音两声；节能开关上电默认关闭。

2. 节能开关打开时，马上进入节能状态；节能开关关闭时，退出且不再自动进入节能状态；

3. 节能开关打开后，产品收到用户操作使用时，退出节能状态，连续1小时没有收到用户操作，产品自动进入节能状态。

4. 进入节能状态，座温档位高于一档，降为一档加热；

5. 退出节能状态，恢复进入节电功能前的座温档位进行座圈加热；

6. 用户操作包括：除打开节能开关操作外，所有遥控器、按键、落座、脚触等操作。

7. 具有并且可以由小程序控制。

# 商务模式

1. 商务功能具有开关。商务开关打开时，提示音一声，商务开关关闭时，提示音两声；商务开关上电默认关闭。

2. 商务模式开关开启时，连续72小时没有收到用户操作（遥控器、按键、落座、脚触等），产品自动进入商务模式。商务模式开关关闭时，不进入商务模式；

3. 产品进入商务模式，关闭座圈加热，关闭除机芯按键外的所有部件操作，不执行任何功能；

4. 产品进入商务模式，按机芯任意按键操作，产品退出商务模式；

5. 退出商务状态，恢复进入商务状态前的座温档位进行座圈加热；

6. 具有并且可以由小程序控制。

# 待机模式

1. 进入待机模式时，机器关闭所有功能，需要退出待机模式才能使用。

2. 离座状态下，长按遥控器的“臀洗”键3秒，机芯提示音响3声，进入待机模式。进入待机模式后，按遥控器任意按键，退出待机模式，并且机芯提示音响3声。
