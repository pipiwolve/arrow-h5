# 产品问答测试集

两份分开用。

`产品问答测试集.jsonl` 共 52 条，是顾问按说明书事实写的原题。问法保持不动，用来和以前的连跑对比。

`产品问答改写测试集.jsonl` 共 36 条。问法不复用上传稿里的 Q 行，覆盖开放列举、口语改写、同义词、缺型号、一句多事实、报修分流、没写的尺寸，以及把别的品牌号码安过来。

两份字段相同。`expect_any` 为空时不生效；有内容时，回答至少命中其中一项。`style` 只给改写集用，标明这条在测哪一种问法。

字段：

| 字段 | 含义 |
| --- | --- |
| id | 稳定编号。AKB 箭牌，FLM 法恩莎，NIL 安华，X 跨型号 |
| brand / model | 应命中的品牌和型号 |
| category | 参数、功能、故障、保养、保修、边界 |
| question | 原话。批量测试时整句送进问答，不要再加占位库里的设备控制提示 |
| expect_contains | 回答里必须同时出现的子串。空数组表示这一侧不查 |
| expect_any | 回答里至少出现其中一项。空数组表示不启用。顾问原题没有这一列 |
| expect_not_contains | 回答里不能出现的子串。空数组表示不查禁词 |
| style | 只在改写集里有。开放列举、同义、口语、多事实、路由、缺型号、边界、串库 |
| note | 人工看回答时的判定说明。自动判分以三个数组为准 |

通过条件：`expect_contains` 全部命中，`expect_any` 至少命中一项，且 `expect_not_contains` 全部不出现。大小写按原文，数字中的连接号要宽松看。例如测试集写 `0.4`，回答写成 `0.40` 仍算命中；写成 `三十五到五十五度` 则 AKB-03 的禁词不一定挡住，这时看 note。

边界题的「未」只要求回答里出现这个字，用来接住「未记载、未区分、没有写明」。若改写意图后回答改用「说明书没写」，把该条的 `expect_contains` 改成「没写」再跑，不要改问题。

NIL-14 要求回答出现「冲突」。上传稿里已经用了这个词。若意图把冲突句术改掉，同步改这一条的期望词。

这套题只覆盖清洗稿里写明的事实。它不测语音能不能下发，也不测设备在线。
