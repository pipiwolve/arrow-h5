# △ 注意事项

☐ 本产品适用于海拔2000m以下的地区使用。

☐ 本产品连接水源时，

清洗水压范围：静压 0.10-0.75MPa；

冲水水压范围：静压 0.02-0.75MPa。

☐ 使用随本产品附带的新软管组件，旧软管组件不宜重复利用。

☐ 如果电源软线损坏，为了避免危险，必须由制造商、其服务机构或类似的专业人员更换。

☐ 本产品属于固定式器具，应由专业人士进行安装、固定于特定位置使用。

☐ 本产品不打算由存在肢体、感官或精神能力缺陷或缺少使用经验和知识的人（包括儿童）使用，除非有负责他们安全的人对他们进行与器具使用有关的监督或指导。

☐ 应照看好儿童，确保他们不玩耍本产品。

☐ 本产品只能与随机配送的停电冲水电池包配套使用。

☐ 本产品电池盒使用5号电池供电。

☐ 产品遥控器使用7号电池供电。

☐ 抓住电池盒本体，向上提拉电池盒上盖即可打开电池盒，打开后可见内部的电池仓，按电池仓上的电池极性提示标注依次插入电池。

☐ 严禁对不可充电电池进行充电。

☐ 请勿混合使用新旧电池。

☐ 请按电池盒电池仓中 + - 正确安装电池。

电池能量耗尽时应及时取出电池，更换新电池。

☐ 废弃电池时，请用胶带等进行绝缘。

请将电池放置在婴幼儿够不到的地方。

☐ 如果产品电池盒长期存放不用，应取出电池。

电池盒的供电端子不应短路。

☐ 本产品必须可靠接地。

☐ 使用过程中，请将家用电器的电源插头完全插入电源插座中，并保持电源插头与插座接触良好。

当需要使用延长线电源插座时，请使用符合国家标准要求的延长线电源插座。

□ 产品出现异常噪声、异常气味、异常高温或故障时，请立即停止使用，关闭开关，断开电源。

☐ 使用者不应自行拆卸家用电器，不应变更内部接线、部件和保护装置。

☐ 从插座上拔下插头时，不应对电源线施加拉力。

# △ 注意事项

☐ 请勿长时间使用座温、暖风/风温的「高」、「中」档。

 $ ^{*} $否则长时间使用会有烫伤的危险。

☐ 在使用过程中，请保持皮肤紧贴座圈感应区域，否则产品会停止清洗或暖风烘干功能。 $ ^{*} $儿童使用时，接触感应区域会比较难。

☐ 请勿将小便淋于清洗器的喷嘴上。

 $ ^{*} $否则产生污垢导致堵塞。

☐ 请不要向产品内冲入新闻纸、纸尿垫、妇用卫生巾等容易堵塞的物品。

☐ 请不要在 $ 0^{\circ} $C以下环境中使用，否则水结冰膨胀会挤破陶瓷体。

 $ ^{*} $否则容易引起漏水导致财产损失。

☐ 当突然停电时，请拔掉电源插头，关闭止水阀，防止漏水。

 $ ^{*} $否则容易引起漏水导致财产损失。

☐ 请避免阳光直射或将取暖器材靠近本产品。

 $ ^{*} $否则可能造成产品变色。

☐ 请不要用重力撞击陶瓷，以防止破损漏水。

☐ 请不要在产品底座埋入胶凝材料（水泥砂浆等），以防止因膨胀而撑裂便器。违规操作造成的不良后果本公司概不负责。

☐ 拆卸过滤器时，请务必关闭止水阀。另外安装过滤器时，请用力拧紧。

 $ ^{*} $否则容易引起漏水

☐ 出差或外出旅游等长时间不使用时，请您务必拔掉电源插头、关闭水源，并将产品内部积水排净。 $ ^{*} $否则冻结内部积水引起的破损会导致火灾、漏水。

☐ 在寒冷的冬季，当产品在经过长途运输或长时间存放时，产品内剩下的积水可能会发生冻结现象。为预防冻结造成损坏，请采取防冻措施。

 $ ^{*} $否则冻结内部积水引起的破损会导致火灾、漏水。

☐ 在安装本产品的同一房间内，需要在触手可及的位置安装一个止水阀，用于紧急情况下，无需借助工具即可切断本产品的进水水路，否则产品的意外故障可能会导致用户损失。

# △警告

为避免由热断路器的误复位产生危险，器具不能通过外部开关装置供电，例如定时器，或者连接到根据功能有规则地进行通、断的电路。

☐ 请勿用湿手触摸或插拔电源插头。

 $ ^{*} $否则有触电的危险。

☐ 请勿使用不良的电源插座或破损的电源插头。

 $ ^{*} $否则接触不良、破损等导致触电或引发火灾等危险。

□ 使用的电源插座请在规定的范围（交流 $ 220V \pm 10\% $，最大电流10A以上）。

 $ ^{*} $否则容易引起火灾、触电。

☐ 请勿把电源线随意拉拽、强行弯曲和扭曲、拉伸、卷曲、打捆、承重、过度夹挤。 $ ^{*} $否则电源线破损会导致触电或火灾。

☐ 非本公司售后维修人员或指定专业维修人员，严禁拆卸、修理、改装本产品。

 $ ^{*} $否则容易引发触电、火灾或异常运作造成人身伤害。

☐ 请勿将点燃的香烟及其他燃烧物投入产品内。

 $ ^{*} $否则容易发生火灾。

☐ 请勿在雷电天气下使用（在附近发生雷电时，请拔下电源插头）。

 $ ^{*} $否则可能会引发事故或发生故障。

☐ 座圈与盖板发生损坏时，为了避免危险请您务必拔掉电源插头、关闭水源，并请联系当地经销商进行更换。

 $ ^{*} $否则容易发生触电、火灾的危险。

☐ 请定期将电源插头拔下，用干布擦拭电源插头上的灰尘。

 $ ^{*} $否则当绝缘不良时，会引起火灾。

☐ 清洁保养塑料部分时，请勿使用不适合的清洁剂（如浓硫酸、浓硝酸、冰醋酸、四氯化碳、氯仿、丙酮、丁酮、苯、甲苯、苯酚、甲酚、二甲基替甲酰胺、甲醚、大豆油、醋酸盐、40%硝酸、浓盐酸、95%酒精、汽油、煤油、刹车油等）。

 $ ^{*} $否则可能导致塑料部分开裂会造成人身伤害、触电或引起火灾。

☐ 请勿将小便射进暖风出口位置。

 $ ^{*} $否则有触电的危险。

☐ 请避免安装在潮湿及易浸到水的浴室内使用。请勿将水喷淋到本产品上面或用水冲洗，以防内部进水，造成损失。

 $ ^{*} $否则容易引起触电、火灾。

☐ 请勿使用工业用水或污染的水源。

 $ ^{*} $否则有可能引起膀胱炎、皮炎及因机械内部腐蚀引起触电、火灾。

☐ 请不要用力向后倚靠、站立在盖板上，或粗暴开闭盖板、座圈，以免造成损坏。

 $ ^{*} $否则容易发生破损、造成人身伤害。

☐ 请勿将手或其他东西塞入暖风出口，在产品使用时请勿覆盖暖风出口。

 $ ^{*} $否则容易引发触电、火灾或异常运作造成人身伤害。

☐ 请勿向产品或遥控器内部加水或清洁剂。请勿用水或清洁剂弄湿产品及电源插头。

 $ ^{*} $否则可能会有触电和发生火灾的危险。

# 产品激活

# 主遥控器的使用方法

# 档位指示灯

关闭所有档位时，3颗指示灯全灭；

1档时，第1颗指示灯常亮；

2档时，第1颗指示灯常亮，第2颗指示灯闪烁；

3档时，第1与第2颗指示灯常亮；

4档时，第1与第2颗指示灯常亮，第3颗闪烁；

5档时，3颗指示灯全亮。

# 冲水

按下此键，马桶执行一次冲水动作，提示音响一声。当不满足冲水条件时，提示音响两声。(为了保护抽水系统防止空抽，间隔约40秒才能进行第二次冲水)

# 深层净洗

短按此键，落座状态下，开启喷枪臀洗，深层净洗功能，默认逻辑如下：

总清洗时长约90秒，分为3个阶段

阶段1：微气泡清洗约30秒

阶段2：微气泡清洗+Ⅰ型3D摆动水型约30秒

阶段3：微气泡清洗+Ⅱ型3D摆动水型约30秒

遥控开启此功能，清洗时长固定约90秒，小程序/APP开启此功能，清洗时长可调节。

# 磐洗

按下“臀洗”键，落座状态下，系统执行臀部清洗功能，清洗时间约90秒，清洗过程中重复按下，可开启/关闭移动清洗。遥控开启此功能，清洗时长固定约90秒，小程序/APP开启此功能，清洗时长可调节。

# 妇洗

按下“妇洗”键，落座状态下，系统执行女性清洗功能，清洗时间约90秒，清洗过程中重复按下，可开启/关闭移动清洗。遥控开启此功能，清洗时长固定约90秒，小程序/APP开启此功能，清洗时长可调节。

# 烘干

着座后，按下遥控器“烘干”键进入暖风烘干（首次启动烘干，会先执行冲水）；在暖风烘干运行中，按下遥控器“停止”键或按下侧面按键停止烘干。

1. 离座时短按遥控器“烘干”键无响应，为错误提示音；

2. 在烘干过程中检测到离座则停止功能运行，在烘干过程中运行其它功能则停止当前功能；3. 暖风周期为约3分钟，当运行周期结束或中途停止后先关闭风热，延时3秒再关闭风机。

4. 在暖风烘干运行中，短按遥控“烘干”键，依次对风速档位进行调节，档位依次为  $ 1 \rightarrow 2 \rightarrow 3 \rightarrow 1 \rightarrow 2 \rightarrow 3 $。

# 停止

按下“停止”键，可以结束臀洗/妇洗/烘干等功能。

# 助便畅洗

当座圈感应到有人落座，在停止或其他模式下按遥控器的“助便畅洗”键，产品会“叮”响一声，开始助便畅洗功能，达到预设清洗时长后，清洗过程自动结束。

如果该功能启动后人员离开座圈，即退出该功能。

清洗过程中单击此键，可通过调节脉冲频率档位调整助便清洗力度；共三档，均响一声。遥控开启此功能，清洗时长固定约180秒，小程序/APP开启此功能，清洗时长可调节。

# 全面护理

短按此键，落座状态下，开启喷枪妇洗全面护理功能，3D摆动水型，默认清洗90秒。遥控开启此功能，清洗时长固定约90秒，小程序/APP开启此功能，清洗时长可调节。

# 喷枪位置调节

按下“喷枪调节+/-”键，改变臀洗或者妇洗的清洗位置档位：1-2-3-4-5档。调节清洗位置时，调节喷枪位置时遥控器指示灯显示档位。

遥控器清洗位置5档：1-2-3-4-5档分别对应APP/小程序10档中的：1-2-5-8-10档。

# 水压调节

按下“水压调节+/-”键，改变臀洗或者妇洗的清洗水压档位：1-2-3-4-5档。调节水压时，调节水压档位时遥控器指示灯显示档位。

# 座温

遥控器进行座温档位调节，对座温档位进行调节，档位依次1-2-3-4-5-4-3-2-1-0档。

# 风温

按下“风温”键，依次改变烘干加热档位：关闭-1-2-3-4-5-4-3-2-1-关闭（往复循环），调节风温时遥控器提示灯显示档位。

# 水温

按下“水温”键，依次改变臀洗/妇洗清洗水加热档位：关闭-1-2-3-4-5-4-3-2-1-关闭（往复循环），调节水温时遥控器指示灯显示档位。

# 夜灯

短按“灯光”键，执行夜灯、氛围灯的开和关动作。

长按遥控器“灯光”按键进行开关自动夜灯功能，功能开响一声“叮”，功能关响两声“叮”当自动夜灯功能开启时，产品感应到用户在微波感应一定范围，夜灯自动打开，当机芯感应不到用户，一定时间后，夜灯自动关闭。

离座状态下，短按此键，可开启全域除菌功能，显示屏全域除菌灯亮起，具体逻辑如下：

第一步，产品自动合盖合圈；

第二步，产品自动给雾化装置进水；

第三步，雾化器进水完成后，执行2分钟的电解过程，开始进行雾化，雾化时间为15分钟；

第四步，开启烘干10秒钟，把雾气吹散；

第五步，排水约1分45秒。

# 注意：

1. 雾化过程自动翻盖翻圈功能暂时失效。若手动执行开盖，则停止工作；

2. 在工作过程中，再次触发该功能/按下遥控器停止按键/机芯侧面多功能按键均可退出该功能；

3. 此功能通过食用盐水雾化成水汽，请避免长时间吸入口鼻。

# 其他功能设定

# 落座检测

在座圈上有落座检测开关，用于检测有无人员落座，只有检测到有人落座后，才能开启“臀洗”、“妇洗”、“烘干”功能，当“臀洗”、“妇洗”、“烘干”功能打开后，人员离开座圈，上述功能将自动关闭。

# 烘干风扇检测

在系统进入烘干模式后，系统会自动检测风扇的状态，当检测到风扇异常烘干功能将自动结束。此功能用于保护烘干发热丝，防止其在无风状态下“干烧”，延长其使用寿命。

# 防低温烫伤

当用户设定座圈温度档位后，当有人落座时，座圈温度自动降到“1”档（设定档位高于1档）以防低温烫伤，若人体离座后，座圈温度回位到用户设定的温度。

# 停电冲水

在智能坐便器停电状态下，插入电池包，并按下电池包上面的按钮，电池包灯光亮起，表示正常给机芯供电，同时开启停电冲水一次。若需要再次冲水，需等待电池包灯光熄灭，再次按下按钮。

注：停电冲水不能替代正常冲水功能，只能在特殊情况下使用。

温馨提示：建议使用电池盒时，将电池盒放置于马桶盖上方或者其他支撑台面上，以免电池盒长期悬空损坏电源线，使用结束后及时将电池盒取下，避免划花马桶外壳。

# 脚感/脚触翻盖翻圈功能

1、脚感触发时间小于2秒为短触。短触时要脚离开感应区后才触发相应的动作，并提示“叮”；

2、短触时执行动作后感应需要先消失，才能再做脚感应判断，且在离座状态下才能触发脚感翻盖翻圈。

3、单独翻盖过程中或单独合圈过程中或翻圈过程中可以继续检测脚感信号，其它过程要等到动作完成后，才能再做脚感应判断。

4、离座状态下，长按遥控器“烘干”键，可控制脚感功能打开/关闭。“叮”响一声，脚感功能打开；“叮叮”响两声，脚感功能关闭。

离座状态下，用户短触

1、当前合盖，执行翻盖；

2、当前上盖打开，若没有过触发落座信号，执行翻圈；

3、当前座圈打开时间小于5秒，执行关圈；

4、当前座圈打开时间约大于或等于5秒，执行合盖合圈并小冲一次。

# 节能功能

1、节能功能具有开关。节能开关打开时，提示音一声，节能开关关闭时，提示音两声；节能开关上电默认关闭。

2、节能开关打开时，连续1小时没有用户使用，产品自动进入节能状态。节能开关关闭时，退出且不再自动进入节能状态；

3、节能开关打开后，产品收到用户操作使用时，退出节能状态，连续1小时没有收到用户操作，产品自动进入节能状态；

4、进入节能状态，座温档位高于一档，降为一档加热；

5、退出节能状态，恢复进入节电功能前的座温档位进行座圈加热；

6、用户操作包括：除“节能模式”键打开节能开关操作外，所有遥控器，落座，脚感/脚触等操作；

7、进入APP/小程序点击“节能模式”键，切换节能开关。

落座时，自动润瓷。

可通过APP/小程序调节自动润瓷，出厂默认开启。

2、离座时长按遥控器“臀洗”键3秒进入待机模式；

3、进入待机模式后，单击遥控器任意按键退出待机模式。

1、用户可调节微波感应角度的档位，具有3档可调；

2、微波感应角度范围设置：1档：70度，2档：50度，3档：30度；（左右扇形角度范围）

# 久坐提醒

2、短按APP/小程序“久坐提醒”键切换功能提醒开/关，打开蜂鸣器响一声，关闭蜂鸣器响两声。

# 其他功能设定

# 脉冲清洗

由APP/小程序控制，在臀洗或者妇洗运行中，脉冲泵通过改变频率，调整清洗过程中的清洗效果；档位为1-3档，当脉冲清洗开关设置关闭时，蜂鸣器响两声。

# 冷热按摩清洗

清洗过程中按下小程序/APP的“冷热清洗”键，打开清洗模式按摩清洗，再次按下“冷热清洗”键，关闭冷热按摩清洗。

清洗过程中，清洗水先5秒不加热，然后15秒加热，循环执行。（水温如果是常温档，不会加热）

# 无菌水功能

机芯内部安装过流水杀菌模块，对流经机芯内部的水进行杀菌，臀洗/妇洗/喷枪自洁时，自动打开模块的杀菌灯进行杀菌；臀洗/妇洗/喷枪自洁结束时自动关闭。

# 智慧温感

1、座温水温根据室内温度自动调节，每隔1小时获取1次室温；

2、当座温智慧温感功能开启时，落座时，通过遥控器或APP/小程序操作调整座温档位，会暂时关闭座温智慧温感功能；离座后，被暂时关闭的智慧温感功能恢复开启；

3、当座温智慧温感功能开启时，离座后，通过遥控器或APP/小程序操作调整座温档位，会暂时关闭座温智慧温感功能；离座并且不再调整座温档位15分钟后，被暂时关闭的智慧温感功能恢复开启；

4、当水温智慧温感功能开启时，执行清洗功能时，通过遥控器或APP/小程序操作调整清洗水温档位，会暂时关闭水温智慧温感功能；离座后，被暂时关闭的智慧温感功能恢复开启；

5、当水温智慧温感功能开启时，离座后，通过遥控器操作调整清洗水温档位，会暂时关闭水温智慧温感功能；离座并且不再调整水温档位15分钟后，被暂时关闭的智慧温感功能恢复开启。

# 其他功能设定

# 阻垢过滤控制

1、用户使用清洗功能(臀洗/妇洗)时将被记录，在用户离座后对使用过的(臀洗/妇洗)管路和自洁管路执行一次阻垢过滤功能；

2、有喷枪电解水功能的机型先执行完喷枪电解水功能后执行阻垢过滤；

3、阻垢过滤控制为主动触发行为，在清洗结束并离座后自动执行；

4、有自动翻圈翻盖功能的机型在执行自动关盖的时候先执行喷枪电解水功能或除菌水功能后再执行阻垢功能；

5、若关掉自动合盖功能，则在离座冲水后先执行喷枪电解水功能或除菌水功能后再执行阻垢功能。

# 喷枪伸出

1、离座状态且不在机芯喷嘴清洗状态下，按下APP/小程序“喷枪伸出”键进入本功能；

2、机芯在喷嘴清洗状态下，按下APP/小程序“喷枪伸出”键或侧面按键退出本功能；

3、在喷嘴清洗过程中，检测到用户着座则退出服务。

# 清扫模式

1、该功能开启后涉及脚感功能、自动润瓷/出泡功能、自动开盖与自动合圈合盖功能、落座感应功能、自动冲水功能等关闭；

2、手动触发本功能，有效执行，蜂鸣器响一声；无效执行，蜂鸣器响两声；

3、小程序/APP设置“清扫模式”开关：

第一步，用户手动触发该按键开启“清扫模式”后，关闭脚感功能、自动润瓷/出泡功能、自动开盖与自动合圈合盖功能、落座感应功能、自动冲水等功能，便于日常卫生清洁；第二步，用户清洁完后，在小程序/APP页面手动关闭该功能，退出“清扫模式”后，坐便器保持进入该模式前的功能状态；

4、短按小程序/APP“清扫模式”按键触发该功能；

5、在工作过程中，再次触发该功能/按下遥控器“停止”键/机芯侧面多功能按键可退出该功能。
